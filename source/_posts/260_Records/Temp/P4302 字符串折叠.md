# 字符串折叠：拼接与周期压缩

> [!question] [P4302 字符串折叠 - 洛谷](https://www.luogu.com.cn/problem/P4302)
> 将字符串写成尽可能短的折叠形式。连续重复的子串可以表示为 `k(S)`，括号中的 `S` 仍然可以继续折叠。

这道题的关键不是寻找整个字符串的一个周期，而是描述一个区间的最优表示从哪里产生。对子串 $s[l\dots r]$，最后一种结构只有两类：

1. 它由左右两段表示直接拼接而成；
2. 整段由某个较短的循环节重复得到。

因此用区间 DP：

$$
f[l][r]=\text{子串 }s[l\dots r]\text{ 的最短表示长度}。
$$

## 两类转移

### 1. 拼接

枚举最后一次分割的位置 $k$：

$$
f[l][r]=\min_{l\le k<r}\{f[l][k]+f[k+1][r]\}.
$$

这一类转移保证了即使整个区间没有周期，也可以由若干个局部可压缩的区间拼起来。

### 2. 周期压缩

设区间长度为 $len=r-l+1$。如果 $p\mid len$，并且 $s[l\dots r]$ 的循环节长度为 $p$，那么整段可以写成：

$$
\frac{len}{p}\bigl(s[l\dots l+p-1]\bigr).
$$

循环节本身也可能继续压缩，所以代价不是裸长度 $p$，而是：

$$
f[l][l+p-1]+\operatorname{digits}(len/p)+2.
$$

其中 $2$ 是一对括号的长度。

```cpp title:"P4302" fold
using namespace std;
using ll = long long;
using ull = unsigned long long;
using i128 = __int128_t;

const int maxn = 100 + 5;
const int mod = 998244353;
const ll inf = 4e18;

ll read( ) {
    ll x = 0, f = 1;
    char ch = getchar( );
    for( ; !isdigit( ch ); ch = getchar( ) ) if( ch == '-' ) f = -1;
    for( ; isdigit( ch ); ch = getchar( ) ) x = x * 10 + ch - '0';
    return x * f;
}

string s;
ll f[maxn][maxn];

int calc( int x ) {
    int res = 0;
    while( x ) {
        res ++;
        x /= 10;
    }
    return res;
}

bool check( int l, int r, int p ) {
    for( int i = l + p; i <= r; i ++ ) {
        if( s[i] != s[i-p] ) return 0;
    }
    return 1;
}

void solve( ) {
    cin >> s;
    int n = s.length( );
    s = " " + s;

    for( int i = 1; i <= n; ++ i ) f[i][i] = 1;
    
    for( int len = 2; len <= n; ++ len ) {
        for( int l = 1; l + len - 1 <= n; ++ l ) {
            int r = l + len - 1;
            f[l][r] = len;

            for( int k = l; k < r; ++ k ) {
                f[l][r] = min( f[l][r], f[l][k] + f[k+1][r] );

                for( int p = 1; p < len; ++ p ) {
                    if( len % p != 0 ) continue;
                    if( check( l, r, p ) ) {
                        int cnt = calc( len / p );
                        f[l][r] = min( f[l][r], f[l][l + p - 1] + cnt + 2 );
                    }
                }
            }
        }
    }
    cout << f[1][n] << '\n';
}
```

区间按长度递增枚举，保证转移依赖的短区间已经求出。判断周期时，可以逐位检查 $s[i]=s[i-p]$。

## 容易遗漏的点

- 周期长度必须整除当前区间长度。
- 括号中的循环节应使用它自己的最优折叠结果。
- 只处理整段周期不够，还需要拼接转移覆盖“局部压缩后再连接”的情况。
- 当前 AC 代码把周期枚举放在分割点循环内部，会产生重复检查；整理后的结构更适合把两类转移分开书写。
