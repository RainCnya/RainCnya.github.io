# LCIS：把结尾值写进状态

> [!question] [P10954 LCIS - 洛谷](https://www.luogu.com.cn/problem/P10954)
> 求两个长度为 $n$ 的序列的最长公共上升子序列长度。

LCIS 同时有两个要求：它既是公共子序列，又严格递增。只记录两个前缀的答案不足以转移，因为接入新元素时还必须知道当前子序列的结尾值。

令：

$$
f[i][j]=\text{只使用 }A_1\dots A_i\text{，并且以 }B_j\text{ 结尾的 LCIS 长度}。
$$

把“结尾位置”写进状态后，递增限制就能通过比较 $B_j$ 处理。

## 转移

从 $i-1$ 推到 $i$ 时：

- 若 $A_i\ne B_j$，不能用 $A_i$ 与 $B_j$ 配对，继承 `f[i-1][j]`；
- 若 $A_i=B_j$，则在所有满足 $B_k<A_i$ 的旧状态后接上当前值：

$$
f[i][j]=1+\max_{k<j,\ B_k<A_i}f[i-1][k].
$$

直接枚举 $k$ 会得到 $O(n^3)$。固定 $i$ 从左向右扫描 $j$ 时，用 `mx` 维护已经遇到的、满足 $B_j<A_i$ 的最大 `f[i-1][j]`，就能省掉第三层循环。

```cpp title:"P10954" fold
using namespace std;
using ll = long long;
using ull = unsigned long long;
using i128 = __int128_t;

const int maxn = 3000 + 5;
const int mod = 998244353;
const ll inf = 4e18;

ll read( ) {
    ll x = 0, f = 1;
    char ch = getchar( );
    for( ; !isdigit( ch ); ch = getchar( ) ) if( ch == '-' ) f = -1;
    for( ; isdigit( ch ); ch = getchar( ) ) x = x * 10 + ch - '0';
    return x * f;
}

int a[maxn], b[maxn];
int f[maxn][maxn];
// a 序列前 i 个数，b 序列前 j 个数，且以 b[j] 结尾的最长公共子序列长度

void solve( ) {
    int n = read( );
    for( int i = 1; i <= n; ++ i ) a[i] = read( );
    for( int i = 1; i <= n; ++ i ) b[i] = read( );

    for( int i = 1; i <= n; ++ i ) {
        int mx = 0;
        for( int j = 1; j <= n; ++ j ) {
            if( a[i] != b[j] ) f[i][j] = f[i-1][j];
            else f[i][j] = mx + 1;
            if( b[j] < a[i] ) mx = max( mx, f[i-1][j] );
        }
    }
    
    int ans = 0;
    for( int j = 1; j <= n; ++ j ) ans = max( ans, f[n][j] );
    cout << ans << '\n';
}
```

`mx` 必须来自上一层 `f[i-1][j]`，否则同一个 $A_i$ 可能在一轮转移中被重复使用。

## 复杂度与空间

- 时间复杂度：$O(n^2)$；
- 当前实现空间复杂度：$O(n^2)$；
- 因为第 $i$ 层只依赖第 $i-1$ 层，可以进一步滚动为 $O(n)$ 空间。

## 记录

这题保留为 **C 类记录**。它把 LIS 中的“结尾值”与 LCS 中的“双序列匹配”结合起来；优化的关键不是换数据结构，而是在固定 $A_i$ 后用一次顺序扫描维护合法前驱的最优值。
