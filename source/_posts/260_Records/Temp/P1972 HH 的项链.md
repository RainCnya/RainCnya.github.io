# HH 的项链：把不同数转化为位置贡献

> [!question] [P1972 HH 的项链](https://www.luogu.com.cn/problem/P1972)
> 给定一个序列，多次询问区间 $[l,r]$ 中不同数的个数。
>
> 数据规模：$n,m,a_i\le 10^6$。

最开始我考虑开一个权值树状数组，维护当前区间内每个权值的出现次数是否大于 $0$。这个信息确实能够表示答案，但不同询问之间需要同时移动左右端点，本质上就是莫队；而且既然每次只查询整个权值域中有多少种数出现，树状数组也可以直接用一个 `tot` 变量代替。

普通莫队可以作为一种正确实现，但复杂度约为 $O((n+m)\sqrt n)$，在本题 $10^6$ 的范围下不够稳。要得到更好的复杂度，需要改变维护的信息，而不是继续优化权值树状数组。

## 把不同数转化为位置贡献

把所有询问按右端点 $r$ 升序排序，并从左向右扫描数组。处理到位置 $r$ 时，对每一种数，只在它截至当前最后一次出现的位置保留一个 $1$：

$$
b_i=
\begin{cases}
1,&i\text{ 是 }a_i\text{ 在 }[1,r]\text{ 中最后一次出现的位置},\\
0,&\text{否则}.
\end{cases}
$$

扫描到位置 $i$，设 $x=a_i$：

1. 若 $x$ 以前出现过，就在 `last[x]` 处减去 $1$；
2. 在当前位置 $i$ 加上 $1$；
3. 更新 `last[x]=i`。

对于询问 $[l,r]$ 中的任意权值 $x$，它在区间内出现，当且仅当它截至 $r$ 的最后出现位置满足

$$
last_r(x)\ge l.
$$

又因为 $last_r(x)\le r$，所以这等价于 $last_r(x)\in[l,r]$。每种数恰好留下一个标记，于是区间不同数个数就转化为

$$
\sum_{i=l}^{r}b_i.
$$

原问题中的“是否出现”没有前缀可减性，不能用两个前缀不同数个数相减；离线扫描的关键，是先把它改写成具有可加性的 $0/1$ 位置贡献，再交给树状数组维护。

按 $r$ 排序也不是因为树状数组只能回答前缀，而是因为当前状态描述的是前缀 $[1,r]$ 中的最后出现位置。让 $r$ 单调增加后，扫描指针只需向右移动，不必撤销后缀并恢复更早的最后出现位置。

时间复杂度为 $O((n+m)\log n)$，空间复杂度为 $O(n+\max a_i+m)$。

```cpp title:"P1972" fold
using namespace std;
using ll = long long;
using ull = unsigned long long;
using i128 = __int128_t;

const int maxn = 1e6 + 5;
const int mod = 998244353;
const ll inf = 4e18;

ll read( ) {
    ll x = 0, f = 1;
    char ch = getchar( );
    for( ; !isdigit( ch ); ch = getchar( ) ) if( ch == '-' ) f = -1;
    for( ; isdigit( ch ); ch = getchar( ) ) x = x * 10 + ch - '0';
    return x * f;
}

struct BIT {
/* ======================================== */
ll tr[maxn];
int sz;
void init( int N ) { sz = N;
    fill( tr, tr + sz + 2, 0 );
}
void add( int idx, ll val ) {
    for( int i = idx; i <= sz; i += i & -i ) tr[i] += val;
}
ll ask( int idx ) {
    ll res = 0;
    for( int i = idx; i; i -= i & -i ) res += tr[i];
    return res;
}
ll query( int l, int r ) { return ask( r ) - ask( l - 1 ); }
/* ======================================== */
} bit;

int a[maxn];
int lst[maxn];
int ans[maxn];

struct Query {
    int l, r, id;
} qs[maxn];

bool cmp( Query x, Query y ) {
    return x.r < y.r;
}

void solve( ) {
    int n = read( );
    for( int i = 1; i <= n; i++ ) a[i] = read( );
    
    int m = read( );
    for( int i = 1; i <= m; i++ ) {
        qs[i].l = read( );
        qs[i].r = read( );
        qs[i].id = i;
    }

    sort( qs + 1, qs + m + 1, cmp );

    bit.init( n );

    int cur = 1;
    for( int i = 1; i <= m; ++ i ) {
        auto [l, r, id] = qs[i];
        for( int j = cur; j <= r; ++ j ) {
            if( lst[a[j]] ) bit.add( lst[a[j]], -1 );
            bit.add( j, 1 );
            lst[a[j]] = j;
        }
        cur = r + 1;
        ans[id] = bit.query( l, r );
    }

    for( int i = 1; i <= m; i++ ) {
        cout << ans[i] << '\n';
    }
}
```

## 莫队版本

这份实现直接维护当前区间内每种权值的出现次数，是前期思路对应的 AC 代码。它与标准离线树状数组版本解决的是同一问题，但复杂度更高。

```cpp title:"P1972-1" fold
using namespace std;
using ll = long long;
using ull = unsigned long long;
using i128 = __int128_t;

const int maxn = 1e6 + 5;
const int mod = 998244353;
const ll inf = 4e18;

ll read( ) {
    ll x = 0, f = 1;
    char ch = getchar( );
    for( ; !isdigit( ch ); ch = getchar( ) ) if( ch == '-' ) f = -1;
    for( ; isdigit( ch ); ch = getchar( ) ) x = x * 10 + ch - '0';
    return x * f;
}

int a[maxn];
int cnt[maxn];
int ans[maxn];
int block;
int tot;

struct Query {
    int l, r, id;
} qs[maxn];

int get_block( int pos ) { return (pos - 1) / block; }

bool cmp( Query x, Query y ) {
    int bx = get_block( x.l );
    int by = get_block( y.l );
    if( bx != by ) return bx < by;
    if( bx & 1 ) return x.r > y.r;
    return x.r < y.r;
}

void add( int pos ) {
    int x = a[pos];
    if( cnt[x] == 0 ) tot ++;
    cnt[x]++;
}

void del( int pos ) {
    int x = a[pos];
    cnt[x]--;
    if( cnt[x] == 0 ) tot --;
}

void solve( ) {
    int n = read( );
    for( int i = 1; i <= n; i++ ) a[i] = read( );
    
    int m = read( );
    for( int i = 1; i <= m; i++ ) {
        qs[i].l = read( );
        qs[i].r = read( );
        qs[i].id = i;
    }

    block = max( 1, (int)( n / sqrt( m ) ) );

    sort( qs + 1, qs + m + 1, cmp );

    int L = 1, R = 0;
    for( int i = 1; i <= m; ++ i ) {
        auto [l, r, id] = qs[i];
        while( L > l ) add( -- L );
        while( R < r ) add( ++ R );
        while( L < l ) del( L ++ );
        while( R > r ) del( R -- );
        ans[id] = tot;
    }

    for( int i = 1; i <= m; i++ ) {
        cout << ans[i] << '\n';
    }
}
```
