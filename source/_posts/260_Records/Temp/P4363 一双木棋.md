# 一双木棋：合法轮廓上的极大极小搜索

> [!question] [P4363 一双木棋 - 洛谷](https://www.luogu.com.cn/problem/P4363)
> 两人轮流在 $n\times m$ 的棋盘上放棋子，落子后棋盘仍需满足题目的轮廓限制。先手获得 $A_{i,j}$，后手获得 $B_{i,j}$，双方都采取最优策略，求最终分差。

直接记录每个格子是否放置需要 $2^{nm}$ 个状态。真正重要的限制是：任意时刻，每一行已经填入的格子一定构成一个前缀，并且各行前缀长度满足：

$$
x_1\ge x_2\ge\cdots\ge x_n.
$$

其中 $x_i$ 表示第 $i$ 行已经填了多少格。于是整个棋盘状态可以压缩为轮廓 $(x_1,x_2,\dots,x_n)$，不必记录每个格子。

## 合法落子

下一枚棋子若放在第 $i$ 行，它的位置只能是 $(i,x_i+1)$。这个位置合法当且仅当：

$$
x_i<m,qquad i=1\ \text{或}\ x_{i-1}>x_i.
$$

第二个条件保证这一行增加后仍不会超过上一行。

状态使用 $m+1$ 进制编码：

$$
state=(((x_1)(m+1)+x_2)(m+1)+\cdots)+x_n.
$$

## 极大极小转移

令 `dfs(state)` 表示从当前局面开始，在双方最优行动下最终得到的“先手得分减后手得分”。已经落下的棋子数决定当前轮到谁：

- 偶数枚：先手行动，枚举落子并取最大值；
- 奇数枚：后手行动，枚举落子并取最小值。

```cpp title:"P4363" fold
using namespace std;
using ll = long long;
using ull = unsigned long long;
using i128 = __int128_t;

const int maxn = 3e5 + 5;
const int mod = 998244353;
const ll inf = 4e18;

ll read( ) {
    ll x = 0, f = 1;
    char ch = getchar( );
    for( ; !isdigit( ch ); ch = getchar( ) ) if( ch == '-' ) f = -1;
    for( ; isdigit( ch ); ch = getchar( ) ) x = x * 10 + ch - '0';
    return x * f;
}

int n, m;
ll a[11][11], b[11][11];
ll x[11];

ll encode( ll x[] ) {
    ll state = 0;
    for( int i = 0; i < n; ++ i ) 
        state = state * ( m + 1 ) + x[i];
    return state;
}

map<ll, ll> memo;

ll dfs( ) {
    ll state = encode( x );
    if( memo.count( state ) ) return memo[state];
    int cnt = 0;
    for( int i = 0; i < n; ++ i ) cnt += x[i];
    if( cnt == n * m ) return memo[state] = 0;

    ll res;
    if( cnt % 2 == 0 ) {
        res = -inf;
        for( int i = 0; i < n; ++ i ) {
            if( x[i] == m ) continue;
            if( i > 0 && x[i] == x[i-1] ) continue;
            int j = x[i];
            x[i] ++;
            res = max( res, a[i][j] + dfs( ) );
            x[i] --;
        }
    } else {
        res = inf;
        for( int i = 0; i < n; ++ i ) {
            if( x[i] == m ) continue;
            if( i > 0 && x[i] == x[i-1] ) continue;
            int j = x[i];
            x[i] ++;
            res = min( res, dfs( ) - b[i][j] );
            x[i] --;
        }
    }
    return memo[state] = res;
}

void solve( ) {
    n = read( ), m = read( );
    for( int i = 0; i < n; ++ i ) {
        for( int j = 0; j < m; ++ j ) {
            a[i][j] = read( );
        }
    }
    for( int i = 0; i < n; ++ i ) {
        for( int j = 0; j < m; ++ j ) {
            b[i][j] = read( );
        }
    }
    cout << dfs( ) << '\n';
}
```

这里没有为“当前玩家”额外开一维，因为棋子总数的奇偶已经唯一决定回合。

## 为什么这个压缩有效

棋盘上已经填入的区域始终是一个阶梯形轮廓。相同的行前缀长度一定对应相同的已填格子集合、相同的当前玩家以及相同的后续选择，因此它是完整状态。

状态数也不是 $(m+1)^n$ 中的所有组合，只有满足单调关系的轮廓能够到达。这比逐格二进制压缩小得多。

## 记录

这题保留为 **C 类记录**。核心增量是：面对看似为棋盘子集的博弈状态，先利用合法局面的几何结构，把二维集合压缩成一条单调轮廓，再在轮廓状态上做记忆化极大极小搜索。
