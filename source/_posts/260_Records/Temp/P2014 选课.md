# 选课：虚拟根上的树形背包

> [!question] [P2014 选课 - 洛谷](https://www.luogu.com.cn/problem/P2014)
> 有 $n$ 门课程，每门课有一个学分，并且至多有一门直接先修课。选出恰好 $m$ 门课程，在满足先修关系的条件下最大化学分和。
>
> $1\le n,m\le300$。

这道题和 [[P1352 没有上司的舞会]] 一样，局部选择之间的影响沿着树边传递。但 P1352 只需要记录根节点选或不选，本题还要求全局恰好选择 $m$ 门课，所以子树向父亲汇报时，必须额外说明自己占用了多少名额。

把每门课的先修课向它连边，会得到一片森林。增加一个权值为 $0$ 的虚拟课程 $0$，把所有没有先修课的课程接在它下面，就可以把森林统一成一棵以 $0$ 为根的树。

虚拟根也视为被选中，因此原问题中选择 $m$ 门真实课程，等价于在新树中选择 $m+1$ 个节点。这样不需要分别处理多个根。

定义

$$
f_{u,i}=\text{在以 }u\text{ 为根的子树中选择 }i\text{ 个节点，且选择 }u\text{ 时的最大学分。}
$$

选择子树中的任何课程都必须先选择 $u$，所以非空状态天然满足先修关系。初始只有根节点自己：

$$
f_{u,1}=val_u.
$$

## 子树之间怎样分配名额

处理 $u$ 的一个儿子 $v$ 时，假设最终从已经处理的部分中选择 $i$ 个节点，并分给 $v$ 的子树 $j$ 个名额，那么转移为

$$
f_{u,i}=\max\left(f_{u,i},f_{u,i-j}+f_{v,j}\right).
$$

每个儿子对应一个“组”：可以完全不选这个儿子的子树，也可以选择其中某个合法规模及其最优价值。因此这一步本质上是树上的分组背包。

代码中 `i` 必须倒序枚举，避免同一个儿子的状态在本轮被重复使用。`j` 从 $1$ 开始；不选择当前子树的情况由原来的 `f[u][i]` 自然保留。

所有状态先初始化为负无穷，只有能够实际构造出的状态才参与转移。否则一个默认值 $0$ 可能被误认为合法方案，尤其在模型扩展到负权或精确选择时会破坏状态语义。

当前实现的时间复杂度为 $O(nm^2)$，空间复杂度为 $O(nm)$。如果记录子树大小并限制枚举范围，可以减少无效循环，但不会改变树上背包的基本转移。

```cpp title:"P2014" fold
using namespace std;
using ll = long long;
using ull = unsigned long long;
using i128 = __int128_t;

const int maxn = 300 + 5;
const int mod = 998244353;
const ll inf = 4e18;

ll read( ) {
    ll x = 0, f = 1;
    char ch = getchar( );
    for( ; !isdigit( ch ); ch = getchar( ) ) if( ch == '-' ) f = -1;
    for( ; isdigit( ch ); ch = getchar( ) ) x = x * 10 + ch - '0';
    return x * f;
}

vector<int> adj[maxn];
// int siz[maxn];
int val[maxn];
ll f[maxn][maxn];
// f[u][i] 表示以 u 为根的子树中，选 i 个点的最大价值
int n, m;

void dfs( int u ) {
    // siz[u] = 1;
    f[u][1] = val[u];

    for( int v : adj[u] ) {
        dfs( v );
        for( int i = m + 1; i >= 1; -- i ) {
            for( int j = 1; j < i; ++ j ) {
                if( f[u][i-j] == -inf || f[v][j] == -inf ) continue;
                f[u][i] = max( f[u][i], f[u][i - j] + f[v][j] );
            }
        }
    }
}

void solve( ) {
    n = read( ), m = read( );

    for( int i = 1; i <= n; ++ i ) {
        int k = read( );
        val[i] = read( );
        adj[k].push_back( i );
    }

    for( int i = 0; i <= n; ++ i ) {
        for( int j = 0; j <= m + 1; ++ j ) {
            f[i][j] = -inf;
        }
    }

    dfs( 0 );
    cout << f[0][m + 1] << '\n';
}
```
