# 最大平均值子段

> [!question] [7792:最大平均段](https://www.tzcoder.cn/acmhome/problemdetail.do?method=showdetail&id=7792)
> 给定一个长度为 $n$ 的数组，选择一个长度至少为 $d$ 的连续子段，使其平均值最大，并输出任意一组最优区间端点。
> 
> 数据规模：$1\le d\le n\le 10^5$，$0\le a_i\le 100$

## 问题抽象

抽象出来的问题是：找到一个长度至少为 $d$ 的连续子段，使得其平均值最大。

如果直接枚举左右端点的话，复杂度为 $O(n^2)$，PASS。

由于问题 “是否存在平均值至少为 $x$ 的合法区间” 是具有单调性的，因此我们想到二分答案。

而这种区间平均值的 check 有一个等价的转换，假设当前二分的平均值为 $x$，区间 $[l,r]$ 的平均至少为 $x$，则有：$\displaystyle \frac{\displaystyle\sum_{i=l}^{r}a_i}{r-l+1}\ge x$ 等价于 $\displaystyle \sum_{i=l}^{r}(a_i-x)\ge 0$

因此可以将每个元素变成 $a_{i} - x$，然后判断是否存在长度至少为 $d$ 的非负和区间。而这样就会遇到第二个问题，区间长度不是固定的，这里可以用到第二个技巧，最大子段和的前缀和做法，因为这个问题也等价于判断 “最大的长度至少为 $d$ 的区间和是否非负”。

固定右端点 $r$，若区间长度至少为 $d$，则左端点前一个位置 $p=l-1$ 满足：$p \le r - d$。此时区间和为：$S_{r} - S_{p}$，为了让区间和尽可能大，我们只需要找到合法范围内最小的前缀和就行了。

由此我们在扫描右端点时，维护当前合法范围内的最小前缀和及其位置即可。


{% fold info @代码 %}
```cpp
int n, d;
double a[maxn], sum[maxn];
int ansl, ansr;

bool check( double x ) {
    sum[0] = 0;
    for( int i = 1; i <= n; ++ i ) {
        sum[i] = sum[i-1] + ( a[i] - x );
    }
    double premin = sum[0];
    int pos = 0;
    for( int r = d; r <= n; ++ r ) {
        int l = r - d;
        if( sum[l] < premin ) {
            premin = sum[l];
            pos = l;
        }
        if( sum[r] - premin >= 0 ) {
            ansl = pos + 1;
            ansr = r;
            return 1;
        }
    }
    return 0;
}

void solve( ) {
    cin >> n >> d;
    for( int i = 1; i <= n; ++ i ) cin >> a[i];
    double l = 0, r = 100;
    ansl = 1, ansr = d;
    for( int t = 1; t <= 100; ++ t ) {
        double mid = ( l + r ) / 2.0;
        if( check( mid ) ) l = mid;
        else r = mid;
    }
    cout << ansl << " " << ansr << '\n';
}
```

## 复盘

最初的想法是从所有长度恰好为 $d$ 的区间出发，尝试向左右扩展。这样能找到所有的合法区间，但最坏复杂度仍然是 $\mathcal{O}(N^{2})$。

同时，扩展后的平均值不存在单调性，不能因为加入一个元素后平均值下降，就停止继续扩展。所以从单调性的角度入手，得到了二分答案的一个思路。

Tricks：最大平均值问题可以通过二分答案，将除法比较转化为区间和判定。
