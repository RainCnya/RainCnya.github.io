# P2245 星际导航

> [!question] [P2245 星际导航](https://www.luogu.com.cn/problem/P2245)
> 宇宙中有若干星系，两个星系之间的直航路线带有一个危险程度。对于每次给出的起点和终点，需要选择一条航行路线，使途中最危险的一段尽可能安全，并输出这个最低可能的危险程度；如果两个星系无法互相到达，则输出 `impossible`。
>
> 数据规模：\(N,Q\le 10^5\)，\(M\le 3\times 10^5\)，边权不超过 \(10^9\)。

这是一个典型的**最小化路径最大边权**问题，也称为 minimax 路径或瓶颈路问题。

朴素做法是在原图上对每次询问单独搜索，并维护到达每个点时路径上的最大边权。但询问数量达到 \(10^5\)，无法接受每次都重新遍历整张图。

关键性质是：对于原图中任意两个连通点 \(u,v\)，它们在任意一棵最小生成树上的路径，其最大边权恰好等于原图中从 \(u\) 到 \(v\) 的所有路径里，最大边权能够取得的最小值。

可以从 Kruskal 的过程理解这个性质。边按照权值从小到大加入，当 \(u,v\) 第一次连通时，当前加入边的权值就是使二者能够连通所必须达到的最小权值上界，而 Kruskal 得到的生成树保留了这个瓶颈值。

由于本题不保证整张图连通，因此实际得到的是一棵**最小生成森林**。对于森林中两个连通点，原图上的瓶颈路问题就转化为了生成树上的路径最大边权查询。

接着问题变成树上路径最大值查询，这个可以配合 LCA 倍增求法快速预处理。

代码的总复杂度为 \(O(M\log M+(N+Q)\log N)\)，空间复杂度为 \(O(N\log N+M)\)。

```cpp title:"P2245 星际导航" fold
struct DSU { /* 模板代码略 */ } dsu;

struct Kruskal {
    int u, v; ll w;
    bool operator < ( const Kruskal &oth ) const { return w < oth.w; }
};
vector<Kruskal> edge;

struct Edge { int v; ll w; };
vector<Edge> adj[maxn];

int up[maxn][maxlg], dep[maxn];
ll mx1[maxn][maxlg];

void dfs( int u, int p, ll w ) {
    dep[u] = dep[p] + 1, up[u][0] = p;
    mx1[u][0] = w;
    for( int i = 1; i < maxlg; ++ i ) {
        int mid = up[u][i-1];
        up[u][i] = up[mid][i-1];
        mx1[u][i] = max( mx1[u][i-1], mx1[mid][i-1] );
    }
    for( auto [v, nw] : adj[u] ) {
        if( v == p )  continue;
        dfs( v, u, nw );
    }
}

int get_lca( int u, int v ) {
    if( dep[u] < dep[v] ) swap( u, v );
    int diff = dep[u] - dep[v];
    for( int i = maxlg - 1; i >= 0; -- i ) {
        if( ( diff >> i ) & 1 ) u = up[u][i];
    }
    if( u == v ) return u;
    for( int i = maxlg - 1; i >= 0; -- i ) {
        if( up[u][i] == up[v][i] ) continue;
        u = up[u][i], v = up[v][i];
    }
    return up[u][0];
}

ll get_max( int u, int anc ) {
    ll mx = -1;
    int diff = dep[u] - dep[anc];
    for( int i = 0; i < maxlg; ++ i ) {
        if( ( diff >> i ) & 1 ) {
            mx = max( mx, mx1[u][i] );
            u = up[u][i];
        }
    }
    return mx;
}

void solve( ) {
    int n = read( ), m = read( );
    for( int i = 1; i <= m; ++ i ) {
        int u = read( ), v = read( );
        ll w = read( );
        edge.push_back({ u, v, w });
    }
    
    sort( edge.begin( ), edge.end( ) );
    dsu.init( n );
    for( auto [u, v, w] : edge ) {
        if( dsu.merge( u, v ) ) {
            adj[u].push_back({ v, w });
            adj[v].push_back({ u, w });
        }
    }

    for( int i = 1; i <= n; ++ i ) {
        if( dsu.find( i ) == i ) dfs( i, 0, 0 );
    }

    int q = read( );
    for( int i = 1; i <= q; ++ i ) {
        int u = read( ), v = read( );
        if( u == v ) {
            cout << 0 << '\n';
            continue;
        }
        if( !dsu.same( u, v ) ) {
            cout << "impossible" << '\n';
            continue;
        }
        int lca = get_lca( u, v );
        ll res = max( get_max( u, lca ), get_max( v, lca ) );
        cout << res << '\n';
    }
}
```

## 记录

- 归属：[[生成树体系]]、[[LCA 体系]]。

- 新增：最小生成树除了最小化整棵树的总边权，还保留任意两点之间的 minimax 瓶颈值，因此一般图上的最小瓶颈路查询可以转化为树上路径最大值查询。

- 辨析：本题使用的是 **Kruskal 最小生成森林 + LCA 倍增**，并不是 Kruskal 重构树。Kruskal 重构树会在每次合并两个连通块时新建节点，并令新节点权值等于当前边权，此时两点瓶颈值可以直接由重构树上的 LCA 权值得到。

- 模型：静态无向带权图 + 多次询问两点间「最小化路径最大边权」时，可以优先考虑最小生成树的瓶颈性质。

- 边界：重边和自环不影响 Kruskal 的正确性；同一点询问在进入 LCA 查询前直接返回 \(0\)。

- 分类：生成树性质 / 瓶颈路 / 树上路径查询。
