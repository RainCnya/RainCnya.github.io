# 降雨量：不完整信息下的三值判定

> [!question] [P2471 降雨量](https://www.luogu.com.cn/problem/P2471)
> 已知部分年份的降雨量。对每个 $Y<X$，判断“$X$ 年是自 $Y$ 年以来降雨量最多的”必真、必假，还是可能成立。
>
> 数据规模：$n\le 5\times10^4$，$m\le10^4$，年份和降雨量均可达 $10^9$。

这句话要求

$$
r_X\le r_Y,
$$

并且对任意 $Y<Z<X$，都有

$$
r_Z<r_X.
$$

问题的麻烦之处不是区间最大值本身，而是部分年份没有记录。整体判定可以压缩成：

```text
已知信息已经产生矛盾 → false
没有矛盾，且 Y 到 X 每一年都已知 → true
其余情况 → maybe
```

## 已知信息何时已经产生矛盾

年份已经按升序给出，所以直接在 `year[]` 上二分，不需要另外用 `map`。`lower_bound` 可以同时判断端点是否已知，并定位 ST 表中的连续下标；`upper_bound(Y)` 与 `lower_bound(X)-1` 则给出严格位于 $Y,X$ 之间的已知年份。

设这些中间记录的最大降雨量为 $mx$。

1. $Y,X$ 都已知时，若 $r_X>r_Y$，端点条件直接矛盾；
2. $X$ 已知时，若 $mx\ge r_X$，中间条件直接矛盾；
3. $X$ 未知而 $Y$ 已知时，需要为 $X$ 选择一个降雨量，使

$$
mx<r_X\le r_Y.
$$

若 $mx\ge r_Y$，这个区间中不存在合法取值，因此仍然是 `false`。

只有不存在上述矛盾，并且 $Y,X$ 均已知、已知记录下标差等于年份差时，才能说明中间没有缺失年份，从而输出 `true`；否则未知年份仍可能改变结论，只能输出 `maybe`。

最开始使用 `map` 时的问题不在容器本身，而在于 `mp[year]` 会给未知年份自动插入值 $0$，破坏“该年份是否已知”这一关键信息；而且把映射后的下标再次当成年份查询，也混淆了年份与离散下标。即使坚持使用 `map`，也需要 `find`、`lower_bound` 和 `upper_bound`，所以直接在已有有序数组上二分更自然。

ST 表只维护已知降雨量的区间最大值。预处理复杂度为 $O(n\log n)$，每次询问进行二分和 $O(1)$ RMQ，复杂度为 $O(\log n)$。

```cpp title:"P2471" fold
struct ST {
/* ======================================== */
int st[maxn][maxlg], lg2[maxn];

void init_lg( int N ) {
    lg2[1] = 0;
    for( int i = 2; i <= N; ++ i ) lg2[i] = lg2[i >> 1] + 1;
}

void init( int N, int val[] ) {
    init_lg( N );
    for( int i = 1; i <= N; ++ i ) st[i][0] = val[i];

    for( int j = 1; ( 1 << j ) <= N; ++ j ) {
        for( int i = 1; i + ( 1 << j ) - 1 <= N; ++ i ) {
            st[i][j] = max(
                st[i][j - 1],
                st[i + ( 1 << ( j - 1 ) )][j - 1]
            );
        }
    }
}

int query( int l, int r ) {
    int k = lg2[r - l + 1];
    return max( st[l][k], st[r - ( 1 << k ) + 1][k] );
}
/* ======================================== */
} st;

int year[maxn], rain[maxn];

void solve( ) {
    int n = read( );

    for( int i = 1; i <= n; ++ i ) {
        year[i] = read( );
        rain[i] = read( );
    }

    st.init( n, rain );

    int q = read( );
    while( q -- ) {
        int Y = read( ), X = read( );

        int py = lower_bound( year + 1, year + n + 1, Y ) - year;
        int px = lower_bound( year + 1, year + n + 1, X ) - year;

        bool hasY = py <= n && year[py] == Y;
        bool hasX = px <= n && year[px] == X;

        int l = upper_bound( year + 1, year + n + 1, Y ) - year;
        int r = lower_bound( year + 1, year + n + 1, X ) - year - 1;

        int mx = 0;
        if( l <= r ) mx = st.query( l, r );

        if( hasY && hasX && rain[px] > rain[py] ) {
            cout << "false\n";
        }
        else if( hasX && mx >= rain[px] ) {
            cout << "false\n";
        }
        else if( hasY && !hasX && mx >= rain[py] ) {
            cout << "false\n";
        }
        else if( hasY && hasX && px - py == X - Y ) {
            cout << "true\n";
        }
        else {
            cout << "maybe\n";
        }
    }
}
```

实现时还出现过两个独立问题：ST 表初始化长度误传为始终等于 $0$ 的 `id`；`hasY`、`hasX` 没有初始化。这些都属于状态语义没有固定清楚：数组下标表示已知记录的位置，布尔量表示端点是否真的存在。
