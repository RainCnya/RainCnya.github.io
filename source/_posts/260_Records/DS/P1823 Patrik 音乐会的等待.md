# P1823 Patrik 音乐会的等待

> [!question] [P1823 Patrik 音乐会的等待](https://www.luogu.com.cn/problem/P1823)
> 给定一个人的身高序列。如果两人相邻，或两人之间没有人比他们都高，则两人能够互相看见。求可见的人对数。
>
> 数据规模：$n\le 5\times 10^5$。

最开始我分别用单调栈求每个人左右两侧的边界，试图认为每个人能看见一个连续区间，再把区间长度累加。

这个计数模型并不成立。对 $i<j$，两人可见的条件是

$$
\max_{i<k<j}a_k\le \min(a_i,a_j),
$$

它不能转化为“$i$ 与某个边界内的所有人都可见”。尤其在出现相同身高时，可见关系会产生一整组组合，单独记录左右第一个更高位置无法表达这些关系。

## 维护仍可能与右侧相见的人

从左向右扫描，维护一个身高严格递减的栈。栈中的节点记录 `(val, cnt)`，其中 `cnt` 表示这一层有多少个相同身高的人。

处理当前身高 $x$ 时，弹出所有不高于 $x$ 的栈顶：

- 栈顶比 $x$ 矮时，这一组人都能看见当前的人，贡献 `cnt`。弹出后，它们会被当前的 $x$ 永久挡住，不再影响未来；
- 栈顶与 $x$ 等高时，这一组人同样都能看见当前的人，贡献 `cnt`，并把它们合并到当前节点中；
- 弹完后若栈仍非空，栈顶一定比 $x$ 高。当前的人还能看见最近的这个更高的人，贡献 $1$，更深处的人则被它挡住。

因此，栈保存的不是普通的“下一个更大元素”，而是从当前位置向左看时，仍没有被更高者永久遮挡的人。相同身高必须压缩计数，否则像 `2 2 2` 这样的序列中，第三个人对前两个同高者产生的两对贡献会被漏掉。

每个人至多入栈、出栈一次，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。答案最大为 $\frac{n(n-1)}2$，需要使用 `long long`。

```cpp title:"P1823" fold
struct Stack {
    int val, cnt;
} stk[maxn];

void solve( ) {
    int n = read( );
    int top = 0;
    ll ans = 0;

    for( int i = 1; i <= n; ++ i ) {
        int x = read( );
        Stack cur = { x, 1 };

        while( top && stk[top].val <= x ) {
            ans += stk[top].cnt;
            if( stk[top].val == x ) cur.cnt += stk[top].cnt;
            -- top;
        }

        if( top ) ++ ans;
        stk[++ top] = cur;
    }

    cout << ans << '\n';
}
```
