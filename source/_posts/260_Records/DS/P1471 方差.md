# P1471 方差

> [!question] [P1471 方差](https://www.luogu.com.cn/problem/P1471)
> 给定一个长度为 $N$ 的序列，有 $M$ 次操作，分别是区间加，区间查询平均值，区间查询方差。
>
> 数据规模：$N, M \le 1e5$。

首先考虑区间加和区间查询平均值，直接维护区间和，然后除以区间长度即可。那么问题就转化到了方差的维护上了。

手推一下方差公式：

$$
\begin{aligned}
S^{2} &= \frac{1}{n} \sum_{i=1}^{n}(A_{i} - \bar{A})^{2} \\
&= \frac{1}{n} \left(  \sum_{i=1}^{n}A_{i}^{2} - 2\bar{A}\sum_{i=1}^{n}A_{i} + \sum_{i=1}^{n} \bar{A}^{2} \right) \\
&= \frac{1}{n} \left(  \sum_{i=1}^{n} A_{i}^{2} \right) - 2 \bar{A}^{2} + \bar{A}^{2} \\
&= \frac{1}{n} \left( \sum_{i=1}^{n} A_{i}^{2} \right) - \bar{A}^{2}
\end{aligned}
$$

所以我们发现只需要额外维护一个区间平方和，就可以算出方差了。

然后难点在于如何下传懒标记，假设我们对 $A[l,\dots, r]$ 区间加 $k$，那么整体就从 $A_{l}^{2} + A_{l+1}^{2} + \dots + A_{r}^{2}$ 变成了 $(A_{l} + k)^{2} + (A_{l+1}+k)^{2} + \dots + (A_{r} + k)^{2}$，拆开柿子然后做个差，就可以得到 $\displaystyle \Delta = 2k \sum_{i=l}^{r} A_{i} + nk^{2}$，于是就可以调用懒标记下传了。

```cpp title:"P1471" fold
#define ls ( u << 1 )
#define rs ( u << 1 | 1 )

struct SegTree {
/* ======================================== */
struct Node { 
    int l, r; 
    double sum1, sum2, add; 
} tr[maxn << 2];

int len( int u ) { return tr[u].r - tr[u].l + 1; }

void push_up( int u ) {
    tr[u].sum1 = tr[ls].sum1 + tr[rs].sum1;
    tr[u].sum2 = tr[ls].sum2 + tr[rs].sum2;
}

void apply( int u, double val ) {
    tr[u].sum2 += 2 * val * tr[u].sum1 +  val * val * len( u );
    tr[u].sum1 += val * len( u );
    tr[u].add += val;
}

void push_down( int u ) {
    if( !tr[u].add ) return ;
    apply( ls, tr[u].add );
    apply( rs, tr[u].add );
    tr[u].add = 0;
}

void build( int u, int l, int r, double val[] ) {
    tr[u].l = l, tr[u].r = r, tr[u].add = 0;
    if( l == r ) { 
        tr[u].sum1 = val[l]; 
        tr[u].sum2 = val[l] * val[l];
        return ; 
    }
    int mid = ( l + r ) >> 1;
    build( ls, l, mid, val );
    build( rs, mid + 1, r, val );
    push_up( u );
}

void add( int u, int l, int r, double val ) {
    if( l <= tr[u].l && tr[u].r <= r ) { 
        apply( u, val ); 
        return ; 
    }
    push_down( u );
    int mid = ( tr[u].l + tr[u].r ) >> 1;
    if( l <= mid ) add( ls, l, r, val );
    if( mid < r ) add( rs, l, r, val );
    push_up( u );
}

double query( int u, int l, int r, int opt ) {
    if( l <= tr[u].l && tr[u].r <= r ) {
        if( opt == 1 ) return tr[u].sum1;
        else return tr[u].sum2;
    }
    push_down( u );
    int mid = ( tr[u].l + tr[u].r ) >> 1;
    double res = 0;
    if( l <= mid ) res += query( ls, l, r, opt );
    if( mid < r ) res += query( rs, l, r, opt );
    return res;
}
/* ======================================== */
} seg;

double a[maxn];

void solve( ) {
    int n = read( ), m = read( );
    for( int i = 1; i <= n; ++ i ) cin >> a[i];

    seg.build( 1, 1, n, a );
    cout << fixed << setprecision( 4 );
    
    for( int i = 1; i <= m; ++ i ) {
        int opt = read( );
        int x = read( ), y = read( );
        if( opt == 1 ) {
            double k;
            cin >> k;
            seg.add( 1, x, y, k );
        }
        else if( opt == 2 ) {
            double sum1 = seg.query( 1, x, y, 1 );
            int len = y - x + 1;
            cout << sum1 / len << '\n';
        }
        else {
            double sum1 = seg.query( 1, x, y, 1 );
            double sum2 = seg.query( 1, x, y, 2 );
            int len = y - x + 1;
            double avg = sum1 / len;
            double ans = sum2 / len - 2 * avg * sum1 / len + avg * avg;
            cout << ans << '\n';
        }
    }
}
```

---

当然还有第二种做法，直接维护平均数与方差。

还可以把题目要求的统计量直接放在线段树结点中。每个结点维护区间长度、区间和、平均数与方差，关键在于这些信息能否由左右儿子合并得到。

设左右区间长度分别为$x,y$，平均数分别为$\mu_L,\mu_R$，方差分别为$s_L,s_R$，合并后的平均数为$\mu$。由方差定义，将左右两部分分别展开：

$$
\begin{aligned}
s
&=\frac{1}{x+y}\left(\sum_{i\in L}(A_i-\mu)^2+\sum_{i\in R}(A_i-\mu)^2\right)\\
&=\frac{x}{x+y}\left(s_L+(\mu_L-\mu)^2\right)
+\frac{y}{x+y}\left(s_R+(\mu_R-\mu)^2\right),
\end{aligned}
$$

其中 $\displaystyle \mu=\frac{x\mu_L+y\mu_R}{x+y}$ 第二步利用了区间内相对自身均值的偏差和为零，即 $\displaystyle \sum_{i\in L}(A_i-\mu_L)=0$ 因此，`push_up` 可以直接合并左右儿子的平均数和方差。

区间整体加上 $k$ 时，平均数增加 $k$，但每个数与平均数的差不变，所以方差不变；懒标记只需要修改区间和、平均数与加法标记。

```cpp title:"方差统计量的合并" fold
struct Node {
    int l, r;
    double sum, add;
    double aveg, s;
} tr[maxn << 2];

struct Info {
    int len;
    double sum, aveg, s;
};

Info merge( const Info &L, const Info &R ) {
    if( L.len == 0 ) return R;
    if( R.len == 0 ) return L;

    Info res;
    res.len = L.len + R.len;
    res.sum = L.sum + R.sum;
    res.aveg = res.sum / res.len;

    int x = L.len, y = R.len;
    res.s = 1.0 * x / ( x + y )
          * ( L.s + ( L.aveg - res.aveg ) * ( L.aveg - res.aveg ) )
          + 1.0 * y / ( x + y )
          * ( R.s + ( R.aveg - res.aveg ) * ( R.aveg - res.aveg ) );
    return res;
}

void push_up( int u ) {
    Info L = { len( ls ), tr[ls].sum, tr[ls].aveg, tr[ls].s };
    Info R = { len( rs ), tr[rs].sum, tr[rs].aveg, tr[rs].s };
    Info res = merge( L, R );
    tr[u].sum = res.sum;
    tr[u].aveg = res.aveg;
    tr[u].s = res.s;
}

void apply( int u, double val ) {
    tr[u].sum += val * len( u );
    tr[u].aveg += val;
    tr[u].add += val;
    // 整个区间同时平移，方差不变。
}
```

这套写法真正容易出错的是查询。方差不能像区间和一样直接相加，也不能使用线段树结点完整区间的平均数。查询必须返回实际命中部分的长度、和、平均数与方差，再使用同一套公式合并：

```cpp title:"部分区间查询" fold
Info query( int u, int l, int r ) {
    if( l <= tr[u].l && tr[u].r <= r ) {
        return { len( u ), tr[u].sum, tr[u].aveg, tr[u].s };
    }

    push_down( u );
    int mid = ( tr[u].l + tr[u].r ) >> 1;
    Info L = { 0, 0, 0, 0 };
    Info R = { 0, 0, 0, 0 };

    if( l <= mid ) L = query( ls, l, r );
    if( mid < r ) R = query( rs, l, r );
    return merge( L, R );
}
```

空分支必须初始化为长度$0$。如果只进入一侧，另一侧保持未初始化，`merge` 读取其中的 `len` 就会产生未定义行为。查询过程也不能把临时合并结果写回 `tr[u]`，否则会用局部查询的信息覆盖结点原本维护的完整区间。

查询平均数与方差可以共用一次结果：

```cpp
Info res = seg.query( 1, x, y );
if( opt == 2 ) {
    cout << res.aveg << '\n';
}
else {
    if( fabs( res.s ) < 1e-9 ) res.s = 0;
    cout << res.s << '\n';
}
```

这种写法使用的是“可合并统计量”：线段树保存的不一定是原始代数和，也可以直接保存能够稳定合并的信息。第一种写法更短、更常见；第二种写法的部分查询较复杂，但更直接地体现了线段树结点信息设计，也解释了为什么区间整体平移无需修改方差。

## 记录

- 归属：线段树结点信息设计。
- 新增：方差既可以由一次和、平方和恢复，也可以作为可合并统计量直接维护；部分查询必须合并实际命中的完整统计信息。
- 易错点：平方和更新必须使用更新前的一次和；直接维护方差时，查询空分支要初始化，查询过程不能覆盖树上原结点的信息。
- 分类：C。
