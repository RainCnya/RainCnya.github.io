# P4513 小白逛公园

> [!question] [P4513 小白逛公园](https://www.luogu.com.cn/problem/P4513)
> 一条路旁依次排列着 $n$ 个公园，每个公园都有一个可能为负的评分。每次游玩会给出两个端点，小白必须在它们之间选择一段非空且连续的公园，使评分总和尽可能大；另外还有操作会把某个公园的评分改成新值。
>
> 数据规模：$n\le 5\times 10^5$，$m\le 10^5$。

这题是 “单点修改” + “区间查询最大子段和”，所以会想到用线段树来维护。

当然，单纯维护区间最大值没法处理跨越中点的子段。所以节点不能只保存区间最大子段和。

由于每一个最大子段和只有三种情况，完全左边，完全右边，跨越中点。所以我们可以为每个节点保存最大前缀和，最大后缀和，区间和以及最大子段和，然后合并即可。具体的合并细节看代码。

这里查询的是非空子段，所以叶子节点的四个和值都应初始化为当前元素本身，不能和空子段取最大值。也就是说，当整个查询区间都是负数时，答案仍然是其中最大的负数，而不是 $0$。

合并还具有方向性，左区间必须放在右区间之前。查询过程中分别维护左侧结果与右侧结果，再按原数组顺序执行 `merge`；代码中的空 `Info` 以 `len == 0` 作为单位元，只负责处理某一侧没有命中的情况，不参与非空子段答案。

建树的时间复杂度为 $O(n)$，单点修改和区间查询的时间复杂度均为 $O(\log n)$，空间复杂度为 $O(n)$。

```cpp title:"P4513 小白逛公园" fold
#define ls ( u << 1 )
#define rs ( u << 1 | 1 )

struct SegTree {
/* ======================================== */
struct Info {
    int len;
    ll sum, mx;
    ll lmx, rmx;
};

struct Node { 
    int l, r;
    Info info;
} tr[maxn << 2];

Info merge( const Info &L, const Info &R ) {
    if( L.len == 0 ) return R;
    if( R.len == 0 ) return L;
    Info res;
    res.len = L.len + R.len;
    res.sum = L.sum + R.sum;
    res.lmx = max( L.lmx, L.sum + R.lmx );
    res.rmx = max( R.rmx, R.sum + L.rmx );
    res.mx = max({ L.mx, R.mx, L.rmx + R.lmx });
    return res;
}

void push_up( int u ) {
    tr[u].info = merge( tr[ls].info, tr[rs].info );
}

void build( int u, int l, int r, ll val[] ) {
    tr[u].l = l, tr[u].r = r;
    if( l == r ) { 
        tr[u].info = { 1, val[l], val[l], val[l], val[l] };
        return ;
    }
    int mid = ( l + r ) >> 1;
    build( ls, l, mid, val );
    build( rs, mid + 1, r, val );
    push_up( u );
}

void upd( int u, int pos, ll val ) {
    if( tr[u].l == tr[u].r ) { 
        tr[u].info = { 1, val, val, val, val };
        return ;
    }
    int mid = ( tr[u].l + tr[u].r ) >> 1;
    if( pos <= mid ) upd( ls, pos, val );
    else upd( rs, pos, val );
    push_up( u );
}

Info query( int u, int l, int r ) {
    if( l <= tr[u].l && tr[u].r <= r ) return tr[u].info;
    int mid = ( tr[u].l + tr[u].r ) >> 1;
    Info L = { }, R = { };
    if( l <= mid ) L = query( ls, l, r );
    if( mid < r ) R = query( rs, l, r );
    return merge( L, R );
}
/* ======================================== */
} seg;

ll a[maxn];

void solve( ) {
    int n = read( ), m = read( );
    for( int i = 1; i <= n; ++ i ) a[i] = read( );
    seg.build( 1, 1, n, a );

    for( int i = 1; i <= m; ++ i ) {
        int opt = read( ), x = read( ), y = read( );
        if( opt == 1 ) {
            if( x > y ) swap( x, y );
            cout << seg.query( 1, x, y ).mx << '\n';
        } else {
            seg.upd( 1, x, y );
        }
    }
}
```
