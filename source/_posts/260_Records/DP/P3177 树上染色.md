# 把同色点对距离拆成每条边被经过的次数

> [!question] [P3177 树上染色](https://www.luogu.com.cn/problem/P3177)
> 在带权树上选择恰好 $m$ 个点染黑，其余点染白。收益为所有黑点对距离之和加上所有白点对距离之和，求最大收益。
>
> 数据规模：$0\le m\le n\le2000$，$1\le w\le10^4$。

这很像一个树上背包模型，但是要考虑每两点之间的距离，就很麻烦了。

但是树上任意两点之间的路径是唯一的，于是我们可以从边的角度计数，分析这一条边被多少对同色点的路径经过。

设儿子子树大小为 $s$，其中选了 $k$ 个黑点。边两侧黑点数量分别为 $k$ 与 $m-k$，白点数量分别为 $s-k$ 与 $n-s-m+k$，因此这条边的贡献是 $[k(m-k)+(s-k)(n-s-m+k)]w$。

定义 `f[u][j]` 表示在 $u$ 子树中选择 $j$ 个黑点时的最大贡献，再按儿子做树上分组背包。儿子选择 $k=0$ 时，源状态和目标状态相同，需要与 $k\ge1$ 的原地转移分开，否则同一个儿子会被合并两次。

```cpp title:"P3177" fold
int n, m;
struct Edge { int v; ll w; };
vector<Edge> adj[maxn];
int sz[maxn];
ll f[maxn][maxn];

void dfs1( int u, int p ) {
    sz[u] = 1;
    for( auto [v, w] : adj[u] ) {
        if( v == p ) continue;
        dfs1( v, u );
        sz[u] += sz[v];
    }
}

void dfs2( int u, int p ) {
    f[u][0] = f[u][1] = 0;
    for( auto [v, w] : adj[u] ) {
        if( v == p ) continue;
        dfs2( v, u );
        for( int j = min( m, sz[u] ); j >= 0; -- j ) {
            if( f[u][j] != -1 ) {
                f[u][j] += f[v][0] + (ll)sz[v] * ( n - m - sz[v] ) * w;
            }
            for( int k = min( j, sz[v] ); k >= 1; -- k ) {
                if( f[u][j-k] == -1 ) continue;
                ll tot = ( k * ( m - k ) + ( sz[v] - k ) * ( n - sz[v] - m + k ) ) * w;
                f[u][j] = max( f[u][j], f[u][j-k] + f[v][k] + tot );
            }
        }
    }
}

void solve( ) {
    n = read( ), m = read( );
    for( int i = 1; i < n; ++ i ) {
        int u = read( ), v = read( );
        ll w = read( );
        adj[u].push_back({ v, w });
        adj[v].push_back({ u, w });
    }

    memset( f, -1, sizeof f );
    dfs1( 1, 0 );
    dfs2( 1, 0 );

    cout << f[1][m] << '\n';
}
```
