# P1450 硬币购物

> [!question] [P1450 硬币购物 - 洛谷](https://www.luogu.com.cn/problem/P1450)
> 有 $4$ 种固定面值的硬币。每次询问给出每种硬币的数量上限 $d_i$ 和目标金额 $s$，求恰好支付 $s$ 的方案数。
>
> $c_i,d_i,s\le10^5$，询问数不超过 $1000$。

如果对每次询问单独做一次多重背包，会重复计算大量只由面值决定的信息。多次询问之间真正变化的是每种硬币的数量上限，而不限制数量时的付款方案数可以统一预处理。

先忽略所有上限，用完全背包求出

$$
f_s=\text{使用四种硬币凑出金额 }s\text{ 的方案数}.
$$

当前实现先读入全部询问，得到最大的目标金额 `mx`，只把完全背包预处理到 `mx`。

## 把超限方案平移回无限制背包

设事件 $E_i$ 表示第 $i$ 种硬币至少使用了 $d_i+1$ 枚。

如果强制事件 $E_i$ 发生，可以先拿出 $d_i+1$ 枚第 $i$ 种硬币。剩余部分仍然可以任意使用四种硬币，所以 $E_i$ 中方案的数量为

$$
f_{s-c_i(d_i+1)}.
$$

更一般地，对于硬币种类集合 $S$，同时要求这些种类超限时，可以预先拿出对应的硬币，方案数为

$$
f_{s-\sum_{i\in S}c_i(d_i+1)}.
$$

这个对应关系是一一的：任何超限方案移除强制拿出的硬币后，得到一个无限制方案；反过来，给任意无限制方案补回这些硬币，也会得到一个满足指定超限事件的方案。

现在全集是所有无限制方案，要求排除 $E_0\cup E_1\cup E_2\cup E_3$。根据容斥原理，答案为

$$
\sum_{S\subseteq\{0,1,2,3\}}(-1)^{|S|}
f_{s-\sum_{i\in S}c_i(d_i+1)}.
$$

硬币种类固定为 $4$，所以每次询问只需枚举 $16$ 个集合。代码使用位掩码统一完成加减，不再手写每一层容斥项。

预处理复杂度为 $O(4\cdot mx)$，每次询问为 $O(16\cdot4)$，空间复杂度为 $O(mx+q)$。方案数需要使用 `long long`。

```cpp title:"P1450" fold
struct Query {
    int d[4], s;
};

int c[4];
ll f[maxn];

void solve( ) {
    for( int i = 0; i < 4; ++ i ) c[i] = read( );
    int q = read( );

    vector<Query> qry( q );
    int mx = 0;

    for( int i = 0; i < q; ++ i ) {
        for( int j = 0; j < 4; ++ j ) qry[i].d[j] = read( );
        qry[i].s = read( );
        mx = max( mx, qry[i].s );
    }

    f[0] = 1;
    for( int i = 0; i < 4; ++ i ) {
        for( int s = c[i]; s <= mx; ++ s ) {
            f[s] += f[s-c[i]];
        }
    }

    for( const Query &cur : qry ) {
        ll ans = 0;

        for( int mask = 0; mask < ( 1 << 4 ); ++ mask ) {
            ll rem = cur.s;

            for( int i = 0; i < 4; ++ i ) {
                if( mask >> i & 1 ) {
                    rem -= 1LL * c[i] * ( cur.d[i] + 1 );
                }
            }

            if( rem < 0 ) continue;

            if( __builtin_popcount( mask ) & 1 ) ans -= f[rem];
            else ans += f[rem];
        }

        cout << ans << '\n';
    }
}
```
