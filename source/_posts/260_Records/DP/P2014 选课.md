# 选课：虚拟根上的树形背包

> [!question] [P2014 选课 - 洛谷](https://www.luogu.com.cn/problem/P2014)
> 有 $n$ 门课程，每门课有一个学分，并且至多有一门直接先修课。选出恰好 $m$ 门课程，在满足先修关系的条件下最大化学分和。
>
> $1\le n,m\le300$。

这道题和 [[200_Publish/260_Records/DP/P1352 没有上司的舞会]] 一样，局部选择之间的影响沿着树边传递。但 P1352 只需要记录根节点选或不选，本题还要求全局恰好选择 $m$ 门课，所以子树向父亲汇报时，必须额外说明自己占用了多少名额。

把每门课的先修课向它连边，会得到一片森林，所以我们考虑直接添加一个虚拟节点 $0$，把所有没有先修课的课程接在它下面，把森林转化成一棵树，这样就好处理了。

定义 $f[u][i]$ 表示在以 $u$ 为根的子树中选择 $i$ 个节点，且选择 $u$ 时的最大得分，因为选择子树中的任何课程都必须先选择 $u$。

所以只需要初始化根节点 $f[u][1] = val[u]$ 即可。

处理 $u$ 的一个儿子 $v$ 时，假设最终从已经处理的部分中选择 $i$ 个节点，并分给 $v$ 的子树 $j$ 个名额，那么转移为：

$$
f_{u,i} = \max\left(f_{u,i},f_{u,i-j}+f_{v,j}\right)
$$

由于每个儿子对应一个“组”：可以完全不选这个儿子的子树，也可以选择其中某个合法规模及其最优价值。所以这一步本质上是一个分组背包模型。

所以 `i` 必须倒序枚举，避免同一个儿子的状态在本轮被重复使用。`j` 从 $1$ 开始；不选择当前子树的情况就是 $f[u][i]$ 不用管。

当前实现的时间复杂度为 $O(nm^2)$，空间复杂度为 $O(nm)$。若是记录子树大小并限制枚举范围，可以减少一些无效循环。

```cpp title:"P2014" fold
vector<int> adj[maxn];
// int siz[maxn];
int val[maxn];
ll f[maxn][maxn];
// f[u][i] 表示以 u 为根的子树中，选 i 个点的最大价值
int n, m;

void dfs( int u ) {
    // siz[u] = 1;
    f[u][1] = val[u];

    for( int v : adj[u] ) {
        dfs( v );
        for( int i = m + 1; i >= 1; -- i ) {
            for( int j = 1; j < i; ++ j ) {
                if( f[u][i-j] == -inf || f[v][j] == -inf ) continue;
                f[u][i] = max( f[u][i], f[u][i - j] + f[v][j] );
            }
        }
    }
}

void solve( ) {
    n = read( ), m = read( );
    for( int i = 1; i <= n; ++ i ) {
        int k = read( );
        val[i] = read( );
        adj[k].push_back( i );
    }
    for( int i = 0; i <= n; ++ i ) {
        for( int j = 0; j <= m + 1; ++ j ) {
            f[i][j] = -inf;
        }
    }
    dfs( 0 );
    cout << f[0][m + 1] << '\n'; // 还要算上虚拟的根节点
}
```
